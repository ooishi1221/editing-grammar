# Editing Grammar v0.1.0

## What it is

Editing Grammar is an agent-readable intermediate layer between editorial intent and renderer execution. It retrieves candidate editing Patterns, preserves their decision and provenance data, and builds a portable handoff after an Agent has selected a Pattern.

## Pipeline

```text
Meaning / Intent
→ Search
→ Candidate Comparison
→ Agent Selection
→ Portable Handoff
→ Video Harness / Renderer Adapter
```

## Included

- Audited Pattern catalog, JSON Schema, TypeScript contract, and provenance separation.
- Deterministic validation, Search v2, Candidate Comparison, and Agent workflow.
- Renderer-neutral implementation grammar and typed implementation parameter declarations.
- Portable Renderer Handoff with input validation and explicit status handling.
- Executable examples, public architecture documentation, contributor guidance, and CI.

## Catalog

- 92 total Patterns
- 81 current-contract
- 3 historical-exception
- 8 semantic-only

## Handoff behavior

Handoff exposes typed declarations, caller-supplied values, and unresolved required inputs. Constants are grammar-owned and cannot be overridden. Semantic-only Patterns return no invented execution grammar. Historical metadata is isolated by default and available only through explicit opt-in. Handoff does not choose a renderer.
