# Editing Grammar v0.2.0

## Summary

Editing Grammar v0.2 adds a second structural layer for composition while
preserving the existing Pattern model.

Patterns answer why the edit exists. Composition answers what receives
attention and what visual relationships are preserved, changed, released, or
restored.

## Highlights

### Composition Grammar

- 6 Frame References
- 4 Sequence References
- 8 Text Roles
- Optional Scene Composition Handoff
- Explicit authored target bindings
- Unresolved required target handling
- Renderer-neutral contract

### HOLD

CS-04 represents intentional composition stability. Text or expression can
change without forcing a reframe.

### Product identity

VS-I15 商品同定・パックショット is new. CF-06 product-identity remains an
independent Composition Reference. Neither automatically selects the other.

### Search v2 retrieval vocabulary

Optional `retrievalTerms` are Pattern-owned, auditable, proposal-provenance
vocabulary for deterministic lexical access. There is no hidden global synonym
dictionary.

「数字を大きく」 now retrieves VS-I05.

Frozen holdout Recall@5 improved from 16/20 to 20/20. The original benchmark
remains Recall@3 22/24, Recall@5 23/24, and pairwise 14/14.

### Validation

`npm run validate` now validates:

- 93 Patterns
- 6 Frame References
- 4 Sequence References
- 8 Text Roles

### Agent workflow

Pattern selection → optional Composition Pass → Scene Handoff → Video Harness
or Renderer Adapter.

Run the executable example:

```sh
npx tsx examples/composition-builder.ts
```

## Catalog status

- 93 total Patterns
- 82 current-contract
- 3 historical-exception
- 8 semantic-only

The original v0.1 source-audited baseline contains 92 Patterns. VS-I15 is the
first post-v0.1 research-derived Pattern.

## Backward compatibility

No intentional breaking changes. Existing Pattern-only workflows and
single-Pattern Handoff remain valid. Composition is optional.

## Still out of scope

- Rendering engine
- Renderer adapter
- NLE
- Automatic recommendation or winner selection
- Composition Search
- Automatic Pattern to Composition mapping
- Asset generation
- npm publication
